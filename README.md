# Frontend Mentor Landing Page

A responsive clone of the Frontend Mentor landing page, built with **HTML**, **Tailwind CSS** and **vanilla JavaScript**.

## Features

- Responsive layout (mobile → desktop)
- Navbar with two dropdown menus (Explore, For Companies)
- Hero section with call-to-action buttons
- Pro banner, testimonials and "As featured on" sections
- Footer with newsletter form and link columns
- Dropdowns close when clicking outside; subscribe button shows a confirmation

## Tech Stack

- HTML5
- [Tailwind CSS](https://tailwindcss.com/) (via CDN, no build step)
- JavaScript (ES6)
- [Font Awesome](https://fontawesome.com/) icons
- Google Fonts (Bungee Shade)

## Project Structure

```
.
├── index.html   # Markup + Tailwind classes
├── script.js    # Dropdown and newsletter logic
└── README.md
```

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Naznighty/<repo-name>.git
   ```
2. Open `index.html` in your browser.

An internet connection is required for the Tailwind CDN, icons and fonts.
